# APIで不足する編集と画面による検証

画面操作前に利用可能な `computer-use:computer-use` スキルを読み、そのツールでResolveを観察する。UI言語にかかわらず現在見えるメニューと値を使う。固定座標や既定ショートカットを画面確認なしに連打しない。

プロジェクト・作業タイムライン・選択項目・トラックをAPIと画面で照合する。sync lock、トラックロック、リンク選択、auto track selectorを把握し、必要な対象だけを変更する。

## 既存クリップのカット・トリム

作業コピーを選び、再生ヘッドを指定タイムコードへ移動する。対象映像とリンク音声を確認して分割コマンドを使う。前後を落とす場合は編集モードを選んで端を調整する。リップルは後続尺を詰め、ロールは隣接境界を動かして全体尺を保つ。ユーザーの指定に合わせる。

フレーム表示とAPIの開始・終了を照合し、グレード・Fusion・キーフレーム、音声同期、他トラックが保たれているか確認する。誤操作時は内容を確認して直前の操作を戻すか作業コピーから復旧し、回数不明のUndoを連打しない。

## 可変速度・タイムリマップ

1. 対象とリンク音声を特定し、Retime Controls / Retime Curve（リタイムコントロール/カーブ）を開く。21のUIは旧版と異なる場合があるので速度/フレームの軸を確かめる。
2. 指定位置がソース時刻か編集後時刻かを区別し、速度ポイントを追加する。速度区間、目標速度、ランプ開始・終了、最終尺を計画に対応させる。
3. 滑らかなランプ指定ならカーブの補間とハンドルを調整する。複数の一定速度クリップを並べた段階的変化を滑らかなランプとして納品しない。
4. 必要なフレーム補間を選び、極端なスローではOptical Flow等の破綻を短い区間で確認する。ソース位置と最終尺も確認する。
5. 音声の速度・ピッチ・同期を聴き、後続クリップと字幕の時刻を再取得する。速度操作後に字幕を配置すると再配置を減らせる。

`GetSpeed()` はカーブ全体の検証には使わない。UIカーブ、特定ソースフレームが現れる位置、再生/プレビュー出力で検証する。

UIが使えずインターチェンジ経路をユーザーが許容する場合は、現行 `ImportTimelineFromFile` が列挙するXML/FCPXML/AAF/OTIO等を検討できる。ただしカーブやトランジションの互換性は形式ごとに異なる。短い独立タイムラインで読み込み・再生を確認してから適用する。未検証のDRT内部書き換えや、無断の焼き込み動画への置換をしない。

## 指定テキスト・SRT字幕

ソース時刻の字幕は編集とリタイムの写像を使って完成タイムライン時刻へ変換する。カットをまたぐ字幕は残った範囲に分割/再配置し、単一オフセットを全字幕に適用しない。可変速度では映像/音声との対応点を確認する。完成タイムライン基準の字幕を二重変換しない。

新規SRTは [../scripts/write_srt.py](../scripts/write_srt.py) で作れる。Python 3.10以降、標準ライブラリのみ。入力例:

```json
{
  "fps": "30000/1001",
  "cues": [
    {"start_frame": 0, "end_frame": 60, "text": "最初の字幕"},
    {"start_frame": 60, "end_frame": 120, "text": "次の字幕\n二行目"}
  ]
}
```

start_frame/end_frameは**完成タイムラインの番組先頭を0**とする整数フレーム、終了はexclusive。絶対開始フレームや01:00:00:00をそのまま加えない。fpsは確認済みの有理数を与える（29.97表記より30000/1001）。ミリ秒は有理数から最も近い値へ丸める。

```powershell
python '<skill-dir>\scripts\write_srt.py' '<work-dir>\captions.json' '<work-dir>\captions.srt'
```

`<skill-dir>` は読み込んだスキルの絶対パス、`<work-dir>` は今回の出力フォルダに置き換える。既存出力は上書きしない。意図した同時表示のみ `--allow-overlap` を指定する。ツール自体は時刻のリマップ、文字起こし、Resolveへの配置を行わない。

Media PoolへSRTをUIで読み込み、字幕トラックへ配置する。読み込み/配置でResolveがどの時刻基準を使ったか最初と最後の字幕で確認する。読み込みだけで配置完了と扱わない。少数なら字幕トラックへ直接追加してInspectorのテキストと開始・終了を設定してもよい。

字幕トラックのスタイルを調整し、日本語対応フォント、文字サイズ、行数、背景/縁取り、画面からの余白をプレビューする。誤字と同期を確認する。焼き込み文字やText+は字幕トラックとは異なるため、用途が合う場合だけ選ぶ。

## クロスフェードの最終確認

境界を拡大しトランジション名・尺・配置を確認する。映像は中央に両ショットが見えること、音声は重なり区間で両方が聴こえることを確認する。黒へのフェードや無音へのフェードをショット間クロスフェードと取り違えない。
